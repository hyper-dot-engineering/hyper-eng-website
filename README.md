# hyper.engineering

Agentic Engineering & Consulting website.

## Structure

```
├── index.html      # Main page (styles + scripts inline, no build step)
├── agents/         # /agents page
└── assets/         # Images
    ├── main.png    # Logo (wide)
    ├── main-s.png  # Logo (square, favicon)
    ├── logo-light-transparent.png
    └── gradient.png
```

## Development

Just open `index.html` in a browser. No build step required.

## Deployment

Hosted via GitHub Pages. Push to `main` to deploy.
